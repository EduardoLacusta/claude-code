# claude-code

Repositório de testes utilizando o **Claude Code** — a CLI oficial da Anthropic para o Claude.

## Objetivo

Este repositório foi criado exclusivamente para testar e explorar as capacidades do Claude Code, incluindo:

- Criação e edição de arquivos
- Operações com Git (commits, push, pull)
- Navegação e análise de código
- Automação de tarefas de engenharia de software

> **Nota:** Este é um repositório de testes. O conteúdo aqui não se destina a uso em produção.
